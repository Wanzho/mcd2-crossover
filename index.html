Install

Five minutes to the title screen.

You’ll need

  • An Apple silicon MacmacOS 13 or later
  • CrossOvertested with 26.3
  • Windows Steam in a bottlewith Dungeons II installed, signed in once
  • A Microsoft accountthe one you play with
Download MCD2‑Crossover‑0.1.3‑arm64.dmgDownload for Mac About 50 MB · Apple silicon · Steam version
  1. 1

    Drag it into Applications.

    Open the download and drag MCD2 Crossover across.

  2. 2

    Open it.

    If macOS blocks it, use Open Anyway in System Settings, as on the right. The app isn’t notarized by Apple yet.1

  3. 3

    Quit the game. Click Set Up.

    Pick your Steam bottle and accept Microsoft’s license. Setup restarts Steam. If Visual C++ is missing, finish Microsoft’s installer when it opens.

  4. 4

    Click Play. Sign in once.

    If a code window appears, sign in on Microsoft’s site with that code and leave the window open until it closes by itself. From then on, play from Steam.

Questions? Answers.

Do I need to own the game?

Yes. It works with your own Steam copy and your own Microsoft account, and the game’s Steam and Xbox ownership checks still run. It doesn’t unlock anything.

Does it see my Microsoft password?

No. You sign in on Microsoft’s website with a one‑time code. The app keeps only the renewal token, in macOS Keychain, and Sign Out deletes it.

Could Microsoft block it?

Possibly. Sign‑in uses the game’s own Microsoft app ID rather than one registered for this tool, so Microsoft could close that route. Use it at your own risk.

What does it change in the game?

It puts Microsoft’s portable Xbox runtime and two compatibility files next to the game, and sets Steam’s launch option for Dungeons II so it starts the game directly. Every file it replaces is backed up. The game’s executable, your saves and your Wine overrides aren’t touched.

The prompts came back after an update. Now what?

Verifying or reinstalling the game can put its original files back. Open MCD2 Crossover and choose Repair Setup… from its menu.

Intel Macs, Game Pass, Minecraft Launcher?

Apple silicon only. The Steam version is the supported one. Minecraft Launcher copies are an experimental, untested option that needs a copy you own there; a Steam purchase doesn’t unlock it. Game Pass and the Xbox app aren’t supported.

Does it work with wasdmod?

Yes. Setup leaves wasdmod’s file and its CrossOver setting alone, and both run in the same bottle. wasdmod adds WASD, mouse and keyboard controls.

What has been tested?

An M5 Pro with CrossOver 26.3: setup, getting into the game, setup in a second bottle, and launching straight from Steam with the app closed. Long sessions, multiplayer, other Macs and installing Visual C++ where it’s missing haven’t been tested yet.

How do I sign out or undo it?

Quit the game, open the app and click Sign Out: that removes the saved credential and session. To undo the repair itself, restore the backed‑up files as described in the technical notes.

Something still fails. Where do I report it?

Click Troubleshooting… in the app, Start Recording, reproduce the problem, then Save Logs… and attach the ZIP to an issue on GitHub, with your Mac and your macOS and CrossOver versions. Passwords, tokens and saves are never in the ZIP.
