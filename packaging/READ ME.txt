MCD2 Crossover

Drag MCD2 Crossover into Applications, then open it there.

You need an Apple Silicon Mac, CrossOver, Windows Steam and your own
Steam copy of Minecraft Dungeons II. Open Steam and sign in once first.

Quit the game before setup. Choose your Steam bottle, read the Microsoft
license and click Set Up. Setup restarts Steam and backs up replaced files.
If Microsoft’s Visual C++ installer opens, finish it to continue.

Click Play. Complete the Microsoft code if asked and leave its small window
open until it closes. Click the link or code to copy it.

After setup and your first sign-in, you can play directly from Steam in
the bottle you set up. You don’t need to open this app every time.
Sign-in renews in the background; the saved Microsoft credential stays
in macOS Keychain. If sign-in stops working, open the app and click Play
to reconnect. Close Window leaves the game running.

To choose another CrossOver bottle, quit the game and click Change Bottle
on the home screen. Choose a bottle with Steam and the game installed,
read the Microsoft license and click Use This Bottle. This keeps your
Microsoft sign-in. Cancel leaves the current bottle unchanged.

To switch Microsoft accounts, quit the game, click Sign Out, then Play.

Browse Game Copy lets you choose a folder or its
Dungeons-…-Shipping.exe. Choose Steam for the tested Steam route.
Minecraft Launcher mode is experimental: it launches an existing Windows
copy through CrossOver, but Windows Store licensing may still block it.
It needs its own valid entitlement; a Steam purchase does not unlock it.
Launcher gameplay has not been tested, and this app does not install the
Launcher or download the game.

For a problem report, open Troubleshooting in the top-right corner, start
recording and reproduce the error. Save the logs and attach the ZIP at:
https://github.com/Wanzho/mcd2-crossover/issues/new/choose
Recording is off by default, stops after one hour and never uploads logs.
The export contains selected, filtered diagnostics, not saved credentials,
game saves or raw request bodies. Review it before sharing.

The app is not notarized. If macOS blocks it, approve it in System Settings
> Privacy & Security. Keep Gatekeeper enabled.

Repair Setup and Force Quit Game are in the MCD2 Crossover menu.
Your saves and controller mods are left alone. Backups are kept in:
~/Library/Application Support/DungeonsCrossOver/backups/

Setup and Play in this app reached the game on an M5 Pro with CrossOver
26.3. A completely new bottle, longer sessions, multiplayer and other
Macs still need testing.

Source, test results and rollback:
https://github.com/Wanzho/mcd2-crossover

Microsoft runtime files are downloaded from Microsoft during setup.
This DMG contains no game files, Microsoft binaries or personal sign-in data.
Python and library license notices are included inside the app.
